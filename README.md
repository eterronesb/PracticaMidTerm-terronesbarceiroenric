## Descripción

PokeMemory es un juego de memoria basado en Pokémon, desarrollado como práctica académica utilizando HTML, CSS y JavaScript.

El jugador crea un perfil, selecciona su Pokémon favorito y participa en partidas en las que debe encontrar parejas de cartas.

## Funcionalidades

- Creación de perfiles con validación del nombre de usuario.
- Búsqueda y selección de Pokémon mediante PokeAPI.
- Persistencia de la sesión mediante sessionStorage.
- Configuración del número de cartas de cada partida.
- Generación aleatoria de parejas de Pokémon.
- Cronómetro y opción de reiniciar partidas.
- Detección de parejas correctas e incorrectas.
- Historial de partidas almacenado en localStorage.
- Ranking ordenado por número de cartas y tiempo.
- Interfaz responsive inspirada en Pokémon para Nintendo DS.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (módulos ES)
- Vite
- PokeAPI
- Git y GitHub
- GitHub Actions y GitHub Pages

## Instalación local

Clonar el repositorio:

```bash
git clone https://github.com/eterronesb/PracticaMidTerm-terronesbarceiroenric.git
```

Entrar en la carpeta e instalar dependencias:

```bash
cd PracticaMidTerm-terronesbarceiroenric
npm install
```

Iniciar el servidor de desarrollo:

```bash
npm run dev
```

## Compilación

```bash
npm run build
```
